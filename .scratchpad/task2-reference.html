变换 Hooks — 移动 / 缩放 / 旋转

Task 2 实现的 5 个文件。逻辑坐标系（1920×1080），所有鼠标/touch 坐标先经 clientToCanvas 除以 scale 换算，再操作 store。

useMove

hook
src/hooks/useMove.ts

批量移动任意数量的选中元素。起点快照 + 拖拽偏移，mouseup 时一次性 pushHistory。

useMove( elementIds: string[], canvasScale: () => number, getCanvasRect: () => DOMRect | null ) → { onMoveStart: (e: MouseEvent | TouchEvent) => void }
参数
  • elementIds — 要移动的 ID 列表
  • canvasScale — 函数（避免闭包过期）
  • getCanvasRect — 函数，返回画布 DOMRect
内部 refs
  • startPosRef — {[id]: {x,y}} 起点快照
  • startMouseRef — 鼠标起点（逻辑坐标）
关键：onMoveStart 内使用 useEditorStore.getState().elements 而非 hook 返回值，避免 React 闭包过期读到旧 state。

useResize

hook
src/hooks/useResize.ts

单元素 8 方向缩放。旋转后不漂移的核心在于全程在元素本地坐标系（已消除旋转）中计算，最后再把新左上角 rotatePoint 回全局系。

useResize( elementId: string, canvasScale: () => number, getCanvasRect: () => DOMRect | null ) → { onResizeStart: (e: MouseEvent | TouchEvent, handle: HandleType) => void }
旋转后缩放不漂移（借鉴 fabric.js）： 鼠标逻辑坐标 → toLocalCoord → 本地系；锚点在本地系中固定；本地系计算新 w/h；新左上角 rotatePoint 回全局 → 更新 x/y/w/h。

8 个手柄的锚点（anchor = 对面手柄中心，元素未旋转坐标系）：

handle锚点 x锚点 y含义
nwx + wy + hse 角
nx + w/2y + hs 边中点
nexy + hsw 角
exy + h/2w 边中点
sexynw 角
sx + w/2yn 边中点
swx + wyne 角
wx + wy + h/2e 边中点
纯垂直手柄（n / s）
  • x 和 w 保持不变
  • 只更新 y 和 h
纯水平手柄（e / w）
  • y 和 h 保持不变
  • 只更新 x 和 w

useRotate

hook
src/hooks/useRotate.ts

单元素自由旋转。以元素中心为原点，用 atan2 计算当前角和起始角之差，连续更新 rotate。

useRotate( elementId: string, canvasScale: () => number, getCanvasRect: () => DOMRect | null ) → { onRotateStart: (e: MouseEvent | TouchEvent) => void }
起点记录
  • 元素中心 → centerRef
  • startAngle = atan2(y−cy, x−cx) − rotate_rad
mousemove 计算
  • cur = atan2(y−cy, x−cx)
  • rotate = (cur − startAngle) × 180/π

RotateHandle

component
src/components/Element/RotateHandle.tsx

旋转手柄，定位于元素顶边中点上方 24px，用一条 1px 竖线连接到元素顶边。

interface RotateHandleProps { onRotatePointerDown: ( e: React.MouseEvent | React.TouchEvent ) => void }
定位细节
  • 手柄圆心：top: -44px，left: 50% 居中
  • 连接线：top: -24px，高 24px，宽 1px，pointerEvents: none
  • 手柄样式：w-5 h-5 rounded-full bg-blue-500 cursor-crosshair

Usage example

在元素容器组件中组合使用的典型写法。

ElementWrapper.tsx（示意）
const { onMoveStart }   = useMove(selectedIds, getScale, getRect)
const { onResizeStart } = useResize(el.id, getScale, getRect)
const { onRotateStart } = useRotate(el.id, getScale, getRect)

<div
  style={{
    position: 'absolute',
    left: el.x, top: el.y, width: el.w, height: el.h,
    transform: `rotate(${el.rotate}deg)`,
    transformOrigin: 'center center',
  }}
  onMouseDown={(e) => onMoveStart(e.nativeEvent)}
  onTouchStart={(e) => onMoveStart(e.nativeEvent)}
>
  {/* 内容 */}
  {isSelected && (
    <>
      <ResizeHandles
        onHandlePointerDown={(e, handle) => onResizeStart(e.nativeEvent, handle)}
      />
      <RotateHandle
        onRotatePointerDown={(e) => onRotateStart(e.nativeEvent)}
      />
    </>
  )}
</div>
